# Yoi

Yoi ouvre les fiches des Bases dans un tiroir à droite, par-dessus la collection et dans le même onglet. Pour Obsidian de bureau 1.15 ou version ultérieure.

## Installer

Décompresser le ZIP dans le dossier `plugins` de la configuration du coffre. Avec la configuration par défaut, `manifest.json`, `main.js` et `styles.css` se trouvent dans `.obsidian/plugins/bases-reading-pane`. Activer **Yoi** dans **Réglages → Extensions communautaires**. Désactiver au préalable tout autre module qui ouvre déjà les fiches au clic.

## Utiliser

Dans une Base, cliquer sur le lien vers une note Markdown. Dans les vues Kanban et Galerie, la formule `link(file.path, file.name)` dans le titre de la carte permet de cliquer sur la carte.

Le tiroir ouvre directement l’éditeur natif d’Obsidian en aperçu en direct. Modifier le texte ou les propriétés comme dans une note ordinaire. Obsidian enregistre les changements automatiquement.

La poignée permet de redimensionner le tiroir à la souris ou avec les flèches quand elle a le focus. Échap ferme le tiroir. Un clic avec une touche de modification garde le geste natif d’Obsidian.
